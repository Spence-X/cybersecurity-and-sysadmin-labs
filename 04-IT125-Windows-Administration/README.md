# 🖥️ IT125: Windows Administration & Systems Portfolio

Welcome to my **IT125 - Introduction to Information Technology** portfolio repository. This repository documents my hands-on laboratory projects, network configurations, troubleshooting logs, and administrative implementations focused on installing, configuring, and administering Windows Desktop and Server systems across peer-to-peer and domain environments.

---

## 📌 Course Overview & Objectives
As part of my Information Technology degree studies, this course builds core competencies required for a desktop support technician, IT generalist, and systems administrator. The primary focus areas include:
* Deploying and updating physical and virtual Windows operating systems.
* Enforcing security postures via Active Directory and Group Policy Objects (GPOs).
* Managing user-accessible hardware, network connectivity, and TCP/IP stacks.
* Administering local and network-connected user rights, security groups, and NTFS permissions.
