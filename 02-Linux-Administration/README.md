# 🐧 Linux System Administration Labs

This folder tracks hands-on exercises in Linux system administration, bash scripting, file permissions, user management, and core command-line operations.

## Lab Roadmap
| Lab Title | Status | Primary Focus |
| :--- | :--- | :--- |
| **Lab 01: Core CLI & File System Operations** | *In Progress* | Shell navigation, directory structures, and file management |
| **Lab 02: User & Permission Management** | *Planned* | `chmod`, `chown`, user groups, and `sudoers` access |
| **Lab 03: Linux Process & Service Management** | *Planned* | `systemctl`, `ps`, process monitoring, and log analysis |
